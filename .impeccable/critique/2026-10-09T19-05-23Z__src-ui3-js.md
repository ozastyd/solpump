# Critique — Pumps page data visibility & readability (src/ui3.js)

Target phrasing: Pumps page (asset directory: detail cards + data matrix)
Assessment date: 2026-10-10. Findings below were assessed before the fix pass; dispositions record the outcome.

## Priority issues

### P0 — State and condition conflated in one pill
The card header, matrix State column, overview fleet Status cell, map popup, and pump-detail header all rendered `pill(st.c, st.label)`: a condition-colored pill labeled with the operational state ("Running" on amber, "Faulted" on red). Color and text argued different things — a Running pump with a warning alarm read as a green "Running" chip and a stopped-yet-critical pump as a red "Stopped".
**Disposition:** resolved. State is now plain text (`.stx`: Running / Stopped / Faulted) beside a canonical condition pill (`Healthy` / `Attention` / `Critical` / `Offline`); offline keeps a single Offline pill (state unknown; last-known is already in meta). Split helpers `stCell`/`condPill` in `ui1.js`, applied at all five sites.

### P0 — Evidence text truncated at evaluation points
Health reason sliced at 44 chars with an appended ellipsis; matrix diagnosis sliced at 42; card note (`.cn`) single-line `nowrap` + `text-overflow: ellipsis`.
**Disposition:** resolved. Health reason and diagnosis render full first-sentence text with `title` attributes; `.cn` is a 2-line clamp with a plain-text `title` on every note.

### P1 — Missing units on well measurements
Card well note read `static 41.2 · drawdown 9.8 m` (unit only on the second value); matrix `Water today` column had no `m³` in the header; well cell drawdown sub-line could wrap mid-value on narrow cells.
**Disposition:** resolved. `static … m · drawdown … m` on the card; matrix header `Water today (m³)`; drawdown sub-line is `white-space:nowrap` + `title`.

### P1 — Light-theme status contrast below AA
`--ok #1C9450`, `--warn #B87D00`, `--crit #C7362B`, `--off #85908B` measured under 4.5:1 on their own tints (worst: off ≈ 2.8:1).
**Disposition:** resolved. Light tokens darkened to `#157A40` / `#8A5D00` / `#B02E24` / `#5E6A65` (all ≥ 4.5:1 on tint, ≥ 4.9:1 on card). Because `--off` is shared (dark theme did not redefine it), an explicit `--off:#8D9A94` was added to both dark override blocks — dark off-pill contrast now 4.96:1 (was 4.39:1). DESIGN.md and `.impeccable/design.json` canonical values + tonal ramps synced.

### P1 — Card typography below comfortable floor
Labels 10px, notes/action 11.5px, diagnosis 12.5px — too small for a scanning surface.
**Disposition:** resolved. `.cl` 11px, `.cn`/`.act` 12px, `.pdg` 13px.

## Accepted layout decisions (locked with user)

- **Horizontal-scroll mobile matrix**: `.tw.wide table { min-width: 900px }` inside the existing `.tw` overflow container — table scrolls inside the panel; document never overflows.
- **KPI strip `.k7` border leaks**: the ≤1280 5-col rules matched the 7-col strip's children (stray right/bottom borders). Scoped to `.kpis:not(.k7)` (guarded `min-width:601px` so ≤600 keeps its 2-col behavior) and gave `.k7` explicit 7/4/2-col divider rules.
